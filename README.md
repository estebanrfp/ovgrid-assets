# OVGrid assets

Since 2026-10-19 [OVGrid](https://world.ovgrid.com)'s texture bank and avatar library are served
from Cloudflare R2 alone, at `https://assets.ovgrid.com/`, and kept on the author's machine: their
copies here, and the repositories `ovgrid-textures-512` and `ovgrid-textures-1024`, are gone.

What stays is `sounds/`: sounds that earlier worlds still load from this repository. They are not
under CC0 or any licence of this repository; each keeps its own.
